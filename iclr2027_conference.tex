\begin{abstract}
\textbf{[작성 가이드: 초록 작성]}

1. 배경: 최근 강화학습에서 세계 모델(World Model) 및 Diffusion 기반 기법들이 널리 쓰이나, 연산량이 너무 크다는 문제 제기.
2. 핵심 발견 (가장 중요): 기존 모델들의 성능이 떨어지는 것은 'Reconstruction(복원)이 안 되어서(Representation이 부족해서)'가 아님을 증명. 사실 인코더는 이미 충분한 정보를 담고 있다.

\section{Are Heavy Representations Necessary?: Decoding the Sufficiency of Encoders}
\textbf{[작성 가이드: 기존 인코더가 이미 충분한 정보를 담고 있음을 증명하는 분석 섹션]}

\subsection{The Myth of Reconstruction Quality}
\begin{itemize}
\item 흔히 범하는 오류: "디코더 이미지가 흐릿하면 정보가 없다"는 착각.
\item \textbf{정성적 증거 (Qualitative Evidence): Temporal Persistence of Objects}
\item 관찰: DreamerV3에서는 잠수함이 물고기에 접근할 때 물고기가 흐려지고 멀어지면 다시 선명해짐. Drama에서는 일정 주기마다 물고기가 흐려졌다가 제자리에 다시 선명해지는 현상이 발생함.
\item 분석: 물고기가 시야에서 벗어나지 않았음에도 다음 프레임들에서 원래 궤적대로 선명하게 다시 나타난다는 사실은, 모델의 Hidden state가 객체의 존재론적(ontological) 정보를 한 순간도 잃지 않았음을 논리적으로 증명함.
\item 결론: 물고기가 흐려지는 것은 인코더의 정보 손실이 아니라, 단순히 디코더(Decoder)의 렌더링 한계(실패)일 뿐임. 즉, Reconstruction Quality는 Representation의 실제 정보량을 판단하는 기만적인(deceptive) 지표임.
\item \textbf{[Figure 삽입 가이드]} 프레임 연속 캡처 사진(Sequence Figure)
    \begin{itemize}
    \item 가로축: 시간 흐름 ($t-1$, $t$, $t+1$)
    \item 세로축 (행): Top (Ground Truth), Middle (DreamerV3 디코딩), Bottom (Drama 디코딩)
    \item 캡션 내용: $t$ 시점에서 디코더는 객체 렌더링에 실패하지만, $t+1$에서 제자리에 완벽히 복원되는 모습을 통해 잠재 상태($z$)의 시간적 지속성(Temporal Persistence)을 보여줌.
    \end{itemize}
\end{itemize}

\subsection{Preliminary Observation: The Cosine Similarity Clue}
\textbf{- [해야 할 실험 결과 삽입]}

\begin{itemize}
\item 연구의 출발점이 된 첫 번째 발견(Motivating Observation) 소개.
\end{itemize}
\begin{itemize}
\item 방법: 화면의 다른 모든 배경은 동일하고 오직 '잠수부의 개수'만 다른 두 Crop 이미지를 인코더에 통과시킴.
\end{itemize}
\begin{itemize}
\item 관찰: 두 이미지에서 추출된 Latent State 간의 코사인 유사도(Cosine Similarity)를 측정해보니 1이 아니라 명확히 1보다 작은 값이 나옴.
\end{itemize}
\begin{itemize}
\item 의미: 만약 인코더가 너무 작아서 안 보이는 잠수부를 통째로 무시(정보 유실)했다면 유사도는 1이 나와야 함. 유사도가 1 미만이라는 사실은, 시각적으로는 보이지 않더라도 인코더가 그 미세한 픽셀 차이(잠수부 유무)를 감지하고 다른 잠재 공간으로 매핑하고 있다는 강력한 단서임. 이를 확실히 검증하기 위해 다음 섹션의 Probing 실험을 진행함.
\end{itemize}

\end{itemize}

\subsection{Robustness to Spatial Noise: Refuting the Blurring Hypothesis}
\textbf{- [해야 할 실험 결과 삽입]}

\begin{itemize}
\item 반박 대상: DIAMOND 등의 최신 Diffusion 모델 논문들이 주장하는 "기존 인코더는 정보가 뭉개지거나(blurr) 위치 정보가 섞인다"는 가설.
\end{itemize}
\begin{itemize}
\item 방법: 원본 이미지에서 잠수부 위치만 그대로 두고, 배경 등 나머지 공간에 랜덤 노이즈를 강하게 주입하여 인코더에 통과시킴.
\end{itemize}
\begin{itemize}
\item 논리: 만약 DIAMOND의 주장대로 잠수부의 정보가 화면의 다른 위치 공간과 섞이거나(blurr) 뭉개졌다면, 다른 위치에 주입된 극심한 노이즈로 인해 잠수부를 검출하는 능력이 크게 훼손되어야 함.
\end{itemize}
\begin{itemize}
\item 결과: "이 상태로 인코딩한 $z$로도 여전히 잠수부의 위치와 개수를 정확히 맞춘다. 이는 인코더가 공간적 정보를 섞지 않고 핵심 객체의 특징을 강건하게(robustly) 분리(disentangle)해내는 능력이 이미 있음을 증명하며, 기존 모델들의 실패 원인이 Blurring 때문이라는 주장을 완벽히 논파한다."
\end{itemize}

\end{itemize}
\begin{itemize}
\item "이는 에이전트가 오프폴리시(Off-policy) 탐험 중 얻은 노이즈 낀 데이터로부터도 정답(Optimal Policy)을 내부적으로 완벽하게 최적화해내고 있다는 강력한 증거다."
\end{itemize}

\end{itemize}
